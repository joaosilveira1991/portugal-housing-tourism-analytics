# Portuguese Housing & Tourism Analytics Pipeline

An end-to-end data analysis project investigating the correlation between tourist accommodation pressure and residential housing price dynamics across Portuguese municipalities (NUTS II & NUTS III regions).

## 📌 Executive Summary
This project extracts, models, and analyzes public statistical records from **INE** (Statistics Portugal) and **PORDATA** to evaluate:
- Median housing sales prices (€/m²) and YoY (year-over-year) growth trends.
- Tourist overnight stays and municipal accommodation revenue.
- Correlation patterns between short-term tourism density and local housing liquidity.

## 🛠️ Tech Stack & Skills
- **Database & Querying:** PostgreSQL (Star Schema, Window Functions, Aggregations, CTEs)
- **Data Engineering & Cleaning:** Python (`pandas`, `numpy`)
- **Data Visualization & BI:** Power BI (Interactive Executive Dashboard, DAX)
- **Version Control:** Git & GitHub
